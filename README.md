# TrazaMed

Plataforma web de gestión de inventario, trazabilidad por lotes y pedidos para distribución de insumos médicos.

## Estado del proyecto

En desarrollo (Sprint 0: preparación y diseño).

## Problema que resuelve

Control de lotes, fechas de caducidad y despacho FEFO (primero en vencer, primero en salir) en distribuidoras de insumos médicos, con trazabilidad completa de cada movimiento.

## Tecnologías previstas

Java 21 · Spring Boot · PostgreSQL · React · Docker · GitHub Actions

## Estructura del repositorio

- `backend/`: API REST
- `frontend/`: aplicación web
- `infra/`: infraestructura y despliegue
- `docs/`: documentación (acta, requisitos, diagramas, ADR)

## Datos

Todos los datos utilizados en este proyecto son ficticios.
